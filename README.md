# 선택 실험실

https://jilzu001.github.io/money-buttons-web/

아이들이 확률을 실험하고, 목표에 맞게 결정하고, 결과와 판단을 구분해 돌아보는 모바일 웹입니다.

## 두 문제

- 기초: 별 2·4·8·20개, 성공 확률 100·50·25·10%. 네 기대값은 모두 별 2개입니다.
- 응용: 기존 1억·4억·30억·1조원, 성공 확률 100·52·23·8%. 기대값 1억·2.08억·6.9억·800억원을 비교합니다. 평균 금액 최대화와 확실한 보상이라는 목표가 다를 수 있습니다.

별과 금액은 가상 보상이며 실제 지급은 없습니다.

## 학습 흐름

1. 확률 연습: 10회·100회 실험, 예상 성공 횟수와 실제 횟수 및 실제 평균 보상을 문제별로 비교합니다. 기록은 화면 메모리에서 유지되며 새로고침 시 초기화됩니다. 연습은 결정 기회를 소비하지 않습니다.
2. 오늘의 결정: 목표와 선택 이유를 적고, 확인 창에서 더 생각하거나 확정합니다. 두 문제를 통틀어 한국시간 날짜별 1회입니다.
3. 돌아보기: 성공 가능성과 목표를 고려했는지 확인하고, 다음에 살펴보고 싶은 정보를 기록합니다. 결과의 좋고 나쁨만으로 판단을 평가하지 않습니다.

오늘의 결정·이유·결과·돌아본 생각은 현재 브라우저 localStorage의 choice-lab-daily-v1에만 저장합니다. Web Locks 지원 브라우저에서는 동시 탭도 하나의 결정을 공유합니다. 한국시간 자정 이후 새 기회가 열립니다. 기존 돈 버튼 기록은 별도 키에 보존하며 교육용 문제의 기록과 합치지 않습니다. 다른 기기, 브라우저, 데이터 삭제에 대한 서버 기반 제한은 아닙니다.

## 이미지와 결과창

기초 결과는 image_gen으로 만든 별·관찰 노트 아트입니다. 응용 결과는 기존 픽셀 금액 아트를 사용합니다. 그림을 따로 여백 안에 넣지 않고, 그림과 설명·확인 버튼을 같은 폭의 하나의 결과창으로 연결합니다. 제목·설명·버튼은 HTML이고 스크린리더에서도 읽을 수 있습니다.

## 개발

python -m http.server 8765
python tools/build_site.py

CSS·JS는 배포 HTML에 묶고 아트를 assets로 복사합니다. main 푸시 시 GitHub Pages에 배포합니다.
