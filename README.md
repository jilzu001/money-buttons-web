# 돈 버튼 · Retro Edition

플레이: https://jilzu001.github.io/money-buttons-web/

노랑·파랑 중심의 고전 2D 게임 스타일 모바일 반응형 확률 체험입니다. 배경은 화면 전체를 채우고 버튼과 픽셀 테두리는 CSS로 그립니다. 이미지, 외부 폰트, 외부 라이브러리, 빌드 과정 없이 HTML·CSS·JavaScript 약 19KB로 구성합니다.

| 버튼 | 당첨 확률 | 금액 |
|---|---|---|
| 노랑 | 100% | 1억원 |
| 파랑 | 52% | 4억원 |
| 주황 | 23% | 30억원 |
| 초록 | 8% | 1조원 |

실패하면 0원입니다. 실제 금전 지급이나 결제는 없으며 매 추첨은 독립적입니다.

## 통계

총 선택, 실제 당첨률, 누적 금액, 버튼별 당첨·선택 횟수와 당첨률을 표시합니다. 막대는 각 버튼의 실제 당첨률입니다. 기록은 이 브라우저의 localStorage에 저장되며 새로고침 후 유지됩니다. 전체 사용자 통계가 아니며 다른 기기와 동기화하지 않습니다. 저장이 차단되어도 현재 화면의 통계는 동작합니다. 초기화는 확인 창에서 승인한 경우만 적용합니다.

## 개발 및 배포

`python -m http.server 8765` 실행 후 `http://localhost:8765`에서 확인합니다. main에 푸시하면 GitHub Actions로 GitHub Pages에 배포됩니다.
