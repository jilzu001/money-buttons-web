# 네 가지 돈 버튼

참고 이미지의 외형을 그대로 사용한 반응형 확률 체험 페이지입니다.
빨강은 100%로 1억원, 파랑은 52%로 4억원, 노랑은 23%로 30억원, 흰색은 8%로 1조원이 표시됩니다. 실패하면 0원입니다. 실제 금전 지급이나 결제는 없습니다.

별도 빌드나 외부 라이브러리가 필요하지 않습니다. `python -m http.server 8765` 실행 후 `http://localhost:8765`에서 확인할 수 있습니다.

GitHub Pages: https://jilzu001.github.io/money-buttons-web/

`main`에 푸시하면 GitHub Actions로 배포됩니다. 참고 이미지에는 사용자가 제공한 원본을 사용했습니다.
