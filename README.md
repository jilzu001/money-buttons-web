# 돈 버튼

https://jilzu001.github.io/money-buttons-web/

네 금액 버튼을 누르면 바로 추첨합니다. 교육 모드·별 문제·설명·통계·확정 단계·필수 입력은 없습니다. 현재 픽셀 결과 아트와 추첨 연출, 결과창의 확인 버튼을 유지합니다.

- 1억원: 100%
- 4억원: 52%
- 30억원: 23%
- 1조원: 8%

한국시간 날짜별 하루 한 번 선택하며, 새로고침해도 유지됩니다. 오늘 결과 확인은 추가 추첨 없이 저장된 결과를 다시 보여줍니다. Web Locks 지원 브라우저에서 탭 간 동시 선택을 제한합니다. 기록은 브라우저에만 저장하므로 다른 기기·브라우저·데이터 삭제에 대한 서버 제한은 아닙니다. 기존 교육 버전에서 오늘 금액 문제를 선택한 경우 그 기록도 유지합니다.

이미지는 assets/rewards-8726928a1a.png를 사용하며 그림과 설명·확인 버튼의 폭을 맞춘 하나의 결과창으로 표시합니다. 실제 금전 지급은 없습니다.

로컬 실행: python -m http.server 8765
배포 파일 생성: python tools/build_site.py
main 푸시 시 GitHub Pages 배포.
